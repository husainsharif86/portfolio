# portfolio

Personal portfolio site for Husain Sharif — plain HTML/CSS, no build step.

## Local preview

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Publishing with GitHub Pages

1. Make this repository public (Settings → General → Danger Zone).
2. Settings → Pages → Source: **Deploy from a branch**, branch `main` / `/ (root)`.
3. The site publishes at `https://husainsharif86.github.io/portfolio/`.

To serve it at the bare `https://husainsharif86.github.io` instead, rename the
repo to `husainsharif86.github.io`.

## Editing

All content is in `index.html`. Search for `TODO` to find the placeholders
(About paragraph, contact links, extra projects).
